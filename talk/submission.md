## Unified topic

Transfinite ordinal game values in infinite chess: what the ordinal value of a position means, why a position has a value exactly when white can force a win, and how positions with values ω, ω², ω³ and ω⁴ are built.

## Selected results and sections

From Evans and Hamkins (2014): Section 2, the definition of game value (Definition 1) and the fundamental observation that valued positions are exactly the winning ones, which we prove in full; Section 3, the positions with value ω (Figure 3), ω² (Figure 7) and ω³ (Figure 10), which we present as worked examples following the paper's analysis; Theorem 4, Conjecture 5 and Theorem 10, which we state without proof.

From Evans, Hamkins and Perlmutter (2017): Theorem 1 and Section 3, the position with value ω⁴ (Figures 1 to 5), its main line of play, the ordinal bookkeeping ω³·r + ω²·h + ω·b + g, and the arguments that deviations from the main line are worse for black, which we present as a proof sketch; Section 4, the compact form of the position (Figure 6).
